# Zpotify v1.1.0

📱 Большой заход на мобильную версию: поиск, свайпы, жесты и плеер стали заметно бережнее к пальцам.

## Для пользователей

🔍 **История поиска** — недавние запросы и клики по трекам/альбомам теперь сохраняются и подсказываются при
следующем открытии поиска
🎯 **Клик по треку в поиске** открывает его альбом/плейлист вместо мгновенного проигрывания
🖼 **Обложки в поиске** — у артистов теперь настоящие аватары, у треков — обложка одного из плейлистов, где он есть
⌨️ **Мобильный поиск** — почему-то пропадало поле ввода, исправлено; клавиатура теперь открывается автоматически
🎴 **Карточки альбомов** — название и артист больше не теряются на светлых обложках
🏠 **Главная на мобильных** — свайп между сегментами больше не дрожит, не проскакивает через несколько экранов и не
залипает при резком свайпе
👆 **Жест «назад»** — системный edge-swipe на Android и аппаратная кнопка «назад» теперь корректно закрывают
диалоги и боковое меню вместо выхода из приложения
📱 **Боковое меню на мобильных** — тап по артисту/плейлисту больше не дублирует переход и не возвращает на главную
📤 **Загрузка папок** — можно перетащить в плейлист сразу целую папку с треками, загрузка идёт пакетно деревом
▶️ **Мобильный плеер** — добавлены кнопки prev/next, белая полоса прогресса и индикатор буферизации; сам прогресс
теперь заливкой в фоне плеера, а не отдельной строкой
📃 **Страница плейлиста на мобильных** — кнопка «назад» выровнена по левому краю, обложка скрывается при скролле
🔧 **Мелкие мобильные фиксы** — увеличены кнопки сайдбара и создания, диалоги больше не вылезают за край экрана,
короткие плейлисты не прилипают к низу

## Технические изменения

🧹 Исправлены ошибки форматирования prettier/stylelint в диалогах
🧪 Добавлена тестовая инфраструктура (vitest + testing-library) с покрытием логики скролла на главной странице
