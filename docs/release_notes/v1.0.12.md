# Zpotify: что нового с v1.0.10

Собрали свежую пачку апдейтов — от уведомлений до артистов и звука 🎧

## 🎁 Для пользователей

🔔 **Уведомления** — колокольчик переехал в чип профиля наверху, рядом с непрочитанной меткой. Открывается общая панель уведомлений, а из пункта в меню аккаунта тоже можно попасть туда же.

🎨 **Редактирование страницы артиста** — теперь можно загружать и менять аватар и обложку артиста прямо со страницы (с учётом прав доступа).

📶 **Прогресс загрузки обложки** — при загрузке обложки плейлиста/артиста показывается индикатор прогресса вместо молчаливого ожидания.

🖇 **Ссылки на артистов** — имена артистов теперь кликабельны везде: в сайдбаре, в ленте и в плеере.

🏠 **Главная страница** — убрали "наезжающую" анимацию обложки при наведении, футер вместо этого просто темнеет; на мобильных сетка альбомов больше не съезжает на 4 колонки.

🎵 **Поддержка M4A** — теперь можно загружать треки в формате M4A.

## ⚙️ Технические изменения

- Добавлен сервис уведомлений: новый proto-контракт, миграция БД, обработчик в Telegram-боте для рассылки уведомлений.
- Обновлена конфигурация линтера (custom-gcl, golangci.yaml, Makefile).
- Вынесены общие компоненты редактирования обложек (EditControls, EditableCoverWithFallback, IconButton) в общий слой для переиспользования.
