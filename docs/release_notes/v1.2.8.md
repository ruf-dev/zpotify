🎵 Большое обновление: торренты, офлайн-режим, мобильный интерфейс и безопасность

**Новое:**
- 🧲 **Загрузка треков через торрент:** можно добавить трек по torrent-файлу или магнет-ссылке — сервер сам скачает и обработает файлы. Есть выбор нужных файлов перед загрузкой, живой прогресс по каждому файлу, повтор дублей, пауза/возобновление/удаление закачек.
- 📴 **Офлайн-библиотека:** отдельная страница для прослушивания уже загруженных треков без сети и без входа в аккаунт.
- 📱 **Полноэкранный мобильный плеер:** открывается тапом по нижней панели.
- 🧭 **Обновлена нижняя навигация на мобильных:** кнопка-лого домой, панель на всю ширину экрана.
- 🍔 **Обновлено мобильное боковое меню:** анимация кнопки-переключателя, выезжает справа, крупнее строки, скелетон профиля.
- 💬 **Telegram-бот:** инлайн-поиск теперь показывает обложки треков и подсказку поиска.
- 🔒 **Безопаснее вход:** авторизация переведена на httpOnly-куки с CSRF-защитой.
- ✨ Мелкие улучшения интерфейса: анимация меню профиля, анимация списка папок при добавлении треков, редизайн пустой панели торрентов.

**Исправления:**
- 🎧 Фоновое воспроизведение больше не обрывается — починено и на iOS (обрыв после конца трека), и на Android.
- 🖼️ Обложки треков снова загружаются (были случайно заблокированы проверкой авторизации).
- 📲 Диалоги добавления трека и создания плейлиста больше не вылезают за край экрана на мобильных.
- 🔑 Вход через Telegram не зависает при недоступности JWKS и не показывает пустой тост при временных ошибках шлюза (502).
- 🧲 Исправлен ряд багов торрент-загрузок: дубли заданий при повторной отправке, пропадающая панель последних торрентов, заблокированный повтор отменённых/неудачных закачек, перетаскивание файла поверх диалога уходило в скачивание браузером.
- 🗄️ Удаление файла теперь каскадно удаляет связанные с ним записи.
- 🚀 Починен критичный баг: миграции базы данных не запускались при старте приложения.

**Технически:**
- Новые RPC для торрент-загрузок: live-обновления через WatchTorrentJobs, Pause/Resume/DeleteTorrentJob.
- Раздельные контракты Upload/List/Submit для выбора файлов торрента.
- Добавлены пробы /livez, /readyz и Version RPC со статус-баннером на фронтенде.
- Починены ретраи 5xx-ошибок шлюза — раньше не срабатывали несмотря на код.
- Dev-сервер: разделены режимы HMR и serve-rc (embedded-сборка), добавлены авто-рестарт и хуки жизненного цикла сессии.

154 коммита с версии v1.1.2 (включая ранее описанные релизы v1.2.0–v1.2.2).
