🎵 Обновление: папки при загрузке, обложки артистов

**Новое:**
- 📁 **Загрузка папками:** при перетаскивании папки с треками структура папок сохраняется, а если папка одна — список показывается плоским, без лишней вложенности.
- ☑️ **Выбор по папкам:** в списке ожидающих файлов можно чекбоксом выбрать все файлы одной папки и сразу создать из них плейлист — с уже загруженными треками и именем плейлиста по названию папки.
- 🗑 **Удаление из очереди:** в диалоге добавления трека теперь можно удалить файл из списка ожидающих, а из карточки трека — вернуться назад к списку.

**Исправления:**
- 🐛 Загрузка двух разных файлов с одинаковым именем больше не приводит к ошибке конфликта.
- 🖼 Обложки альбомов на странице артиста больше не пропадают, а синглы и фичеринг в списке треков теперь тоже показывают обложку.
