🎵 Обновление: загрузка торрентами и офлайн-библиотека

**Новое:**
- 🧲 **Загрузка треков через торрент:** можно добавить трек по torrent-файлу или магнет-ссылке — сервер сам скачает и обработает файлы.
- ⏯ **Управление загрузками:** в диалоге торрентов появились пауза, возобновление и удаление — процессом закачки теперь можно управлять, а не только наблюдать.
- 📴 **Офлайн-библиотека:** отдельная страница, где можно слушать уже загруженные треки без сети и без входа в аккаунт.

**Исправления:**
- 🎧 Фоновое воспроизведение больше не останавливается само через несколько треков.

**Технически:**
- Новые RPC `PauseTorrentJob`/`ResumeTorrentJob`/`DeleteTorrentJob` и статус `paused` для torrent-загрузок.
- Локальный `make serve` теперь собирает и встраивает UI-бандл вместо проксирования vite dev-сервера; обновлён ingress-конфиг.
- Telegram-бот больше не падает на пустом `TelegramProxyURL` — прокси подключается только когда он задан.
