# Zpotify v1.0.13

📦 Значительное обновление: переработанный мобильный плеер, полнотекстовый поиск и офлайн-режим приложения.

## Для пользователей

🎧 **Мобильный плеер переработан** — только самое нужное: кнопка play/pause и полоса прогресса, кнопка «Добавить»
переехала в боковое меню
👆 **Тактильный отклик на тапы** — лёгкое затемнение и масштаб при нажатии на карточки/строки, смена трека в плеере
теперь с плавной анимацией
🔍 **Полнотекстовый поиск** по артистам, плейлистам и трекам
🖼 **Обложки альбомов кешируются** — при возврате назад больше не перезагружаются
📲 **Zpotify можно установить как веб приложение** — работает офлайн, убрали чёрный экран при запуске
▶️ **Меньше пауз между треками** — следующий трек в очереди подгружается заранее
🎯 **Исправлена случайная навигация на страницу артиста** при тапе по треку; 
📤 **Треками можно поделиться прямо в Telegram**
🔙 **Кнопка «назад» на странице артиста** больше не прячется под обложкой
🔐 **Исправлена вспышка экрана логина** при валидной сессии; убраны дублирующиеся уведомления «сессия истекла»
