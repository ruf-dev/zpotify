🎧 **Патч v1.0.9**

Лента на главной, глобальная очередь плеера, управление треками в плейлистах и куча починок аплоада.

**✨ Что нового для пользователей**
🏠 **Лента на главной** — хронологическая лента новых плейлистов, треков и артистов, с датой-заголовком и каруселью
✂️ **Очистка названий при мультизагрузке** — можно срезать номера треков в начале имени файла
📂 **Кэш по альбомам** — закешированные песни сгруппированы по альбомам, с массовым удалением
⬆️ **Прогресс загрузки обложки** — обложка плейлиста показывает индикатор загрузки, пока грузится
🔁 **Повтор неудачных загрузок** — при мультизагрузке можно повторить отдельные или все упавшие треки
🎵 **Управление треками плейлиста** — можно добавлять и удалять треки на уже созданном плейлисте
⏯️ **Плей/пауза и приватность на экране плейлиста** — добавлены переключатель воспроизведения и индикатор приватного
плейлиста

**🐛 Исправления**

- очередь плеера переживает переходы — глобальная очередь воспроизведения больше не сбрасывается при навигации по
страницам
- обложка альбома/плейлиста не обновлялась без перезагрузки страницы после редактирования
- двойной запрос при выборе или создании артиста в ArtistPicker
- на странице альбома у треков не отображался артист — только фиты
- загруженные файлы теряли права на чтение после атомарного переноса/копирования
- клик по играющему треку перезапускал его вместо паузы
- уведомление в трее показывало имя файла и аккаунта вместо названия трека, артиста и обложки
- приватность плейлиста, выставленная через режим редактирования, не сохранялась
- сортировка списка песен по убыванию применялась только к глобальной очереди
- дубликаты песен в плейлисте были запрещены — теперь разрешены
- зависание сервера и застрявшее состояние клиента при обрыве мультизагрузки (мёртвый wifi, уснувший ноутбук, закрытая
  вкладка)
- сайдбар перекрывал плеер-бар
