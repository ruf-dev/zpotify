🎧 **Минорный патч v1.0.4**

Поиск, лайки, оффлайн-кэширование, мобильный интерфейс и куча чистки под капотом.

**✨ Что нового для пользователей**
📥 **Оффлайн-кэширование** — можно скачивать треки для прослушивания без интернета; В настройки добавлена панель со списком скачанных треков. Закешированные треки отображают небольшой зелёный огонёк рядом с названием
📱 **Мобильный интерфейс** — новая нижняя навигационная панель, боковое меню выезжает как шторка, меню профиля выезжает снизу
❤️ **Лайки** — понравившиеся треки автоматически попадают в личный плейлист «Likes»
🔒 **Приватные плейлисты** — можно оставлять плейлисты только для себя

🔍 **Страница поиска** — Начата разработка. Пока что только мок без реального поиска

**🐛 Исправления** 
- диалоги теперь закрываются нажатием мимо диалога
- исправлен баг, когда трек с некорректным названием зависал в кеше и терялся после перезагрузки

**🔧 Технические изменения**

🧹 Полный проход **golangci-lint** по всему бэкенду — инициализация приложения, сервисный слой, слой хранилища, транспортный слой, middleware, локализация, сборщик мусора сессий, Telegram OIDC, тесты
📦 Клиентский код перенесён из `pkg/web` в `pkg/client` (техдолг)
🗂️ Рефакторинг и разбиение виджетов сайдбара и экрана плейлиста для удобства поддержки
🧩 Диалоги переведены на общую UI-библиотеку **chures** и приведены в соответствие с FSD-архитектурой и правилами линтера (заодно починен баг с молчаливым падением обработки ошибок при логине)
⌨️ Сырые `<input>` элементы заменены на компонент `Input` из chures, удалён почти-дубликат `FloatInput`
🔐 Убраны недоделанные и неиспользуемые альтернативные способы авторизации

_47 коммитов, много рефакторинга — всё ради более чистого и функционального приложения._
